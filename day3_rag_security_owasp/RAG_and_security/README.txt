SIMPLE RAG PDF STEP-BY-STEP
===========================

Files:
- Simple_RAG_PDF_Step_by_Step.ipynb
- BASEL.pdf
- COI.pdf
- rag_validation_questions.csv
- requirements.txt
- .env.example

Flow:
1. Load validation questions
2. Check without RAG
3. Load PDFs
4. Split into chunks
5. Create embeddings
6. Store in Chroma
7. Retrieve documents
8. Create RetrievalQA
9. Generate RAG answers
10. Evaluate without RAG
11. Evaluate with RAG
12. Check citation/source match
13. Check groundedness
14. Check retrieval success
15. Compare final scores
